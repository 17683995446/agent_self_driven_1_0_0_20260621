## 第一性原理

智能的本质是：
1. **预测** - 基于历史推断未来
2. **修正** - 基于误差调整模型
3. **进化** - 基于驱动持续优化

## 核心循环

1. **感知** → 获取环境状态
2. **评估** → 计算驱力奖励与缺口
3. **决策** → 生成任务并选择最优
4. **执行** → 并发执行任务
5. **记忆** → 存储经验
6. **监控** → 检测趋势与异常
7. **睡眠** → 离线复盘与进化

## 安全机制

- **刚性护栏**：CPU/内存/磁盘上限检查
- **快照回滚**：自动保存状态，异常时回滚
- **异常检测**：实时监控系统健康
