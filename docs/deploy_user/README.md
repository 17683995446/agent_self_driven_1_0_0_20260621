## 命令速查

```bash
# 启动（默认 prod 环境）
./scripts/start.sh

# 指定环境启动
./scripts/start.sh --env dev

# 验证配置不启动
self-driven-agent --dry-run

# 查询运行状态
self-driven-agent --status

# 停止
./scripts/stop.sh

# 查看版本
self-driven-agent --version
```

更多示例见 [快速开始](quick_start.md)。
