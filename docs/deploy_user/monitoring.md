## 监控指标

### 系统指标
- CPU使用率
- 内存使用率
- 磁盘使用率
- 进程数量

### 业务指标
- 进化指数
- 预测精度
- 任务成功率
- 探索/利用比例

### 健康指标
- 组件健康状态
- 异常事件数量
- 快照数量

## 告警规则

| 条件 | 级别 | 动作 |
|------|------|------|
| CPU > 80% | WARNING | 日志告警 |
| CPU > 95% | CRITICAL | 触发回滚 |
| 内存 > 80% | WARNING | 日志告警 |
| 内存 > 95% | CRITICAL | 终止进程 |
| 预测误差突增30% | HIGH | 记录异常 |
| 进化停滞20周期 | MEDIUM | 增加探索 |
